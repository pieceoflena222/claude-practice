# 강사료 노트 (예온컴퍼니)

휴대폰에서 강의를 입력하면 구글시트에 바로 기록되는 강사료 관리 앱입니다.
월별·연간 합계, 세금(3.3% / 8.8% / 세금계산서), 여비, 페이백, 보조강사 지급을 함께 관리합니다.

| 파일 | 역할 |
|---|---|
| `Code.gs` | 시트 만들기, 계산식, 앱 서버 (Google Apps Script) |
| `Index.html` | 휴대폰 앱 화면 |
| `appsscript.json` | 시간대·웹앱 권한 설정 (선택) |

---

## 1. 처음 설치 (약 10분, PC에서 한 번만)

1. **새 구글시트 만들기**: [sheets.new](https://sheets.new)에서 새 시트를 만들고 이름을 `강사료관리_2026`으로 정합니다.
2. **Apps Script 열기**: 상단 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. **코드 붙여넣기**
   - 왼쪽의 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
   - 파일 옆 **＋ → HTML**을 눌러 이름을 `Index`로 만들고, `Index.html` 내용을 붙여넣습니다.
   - 💾 저장합니다.
4. **시트 설정 실행**
   - 구글시트 탭으로 돌아가 새로고침하면 상단에 **강사료관리** 메뉴가 생깁니다.
   - **강사료관리 → ① 처음 설정**을 누르고 연도(2026)를 입력합니다.
   - 처음에는 권한 승인 창이 뜹니다. 본인 계정을 선택한 뒤 **고급 → (안전하지 않음)으로 이동 → 허용** 순서로 누릅니다. 직접 만든 스크립트라서 나오는 안내입니다.
5. **휴대폰 앱 배포**
   - Apps Script 화면 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 ⚙ → **웹 앱**을 고릅니다.
   - **다음 사용자 인증정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 나만** ← 꼭 이 값으로 설정하세요 (보안)
   - **배포**를 누르면 나오는 **웹 앱 URL**을 복사합니다.
6. **안드로이드 홈 화면에 추가**
   - 크롬에서 URL을 열고 **⋮ → 홈 화면에 추가**를 누릅니다.
   - 처음 열 때 **PIN(숫자 4~8자리)**을 두 번 입력해서 정합니다.

> 크롬에 구글 계정이 여러 개 로그인되어 있으면 웹앱이 열리지 않을 수 있습니다.
> 그럴 때는 이 시트 계정 하나만 로그인된 크롬 프로필에서 여세요.

## 2. 보안

- **1단계 (구글 계정)**: 웹앱 접근 권한이 "나만"이면 내 구글 계정으로 로그인하지 않은 사람은 열 수 없습니다.
- **2단계 (PIN)**: 앱을 열 때마다 PIN을 입력합니다.
  - 앱을 닫으면 다시 물어봅니다. 열어 둔 상태로 최대 6시간까지 유지됩니다.
  - 5번 틀리면 10분 동안 잠깁니다.
- PIN을 잊었을 때는 시트 메뉴 **강사료관리 → 앱 PIN 초기화**를 누르면 됩니다. 기존 로그인도 모두 해제됩니다.
- PIN은 코드가 아니라 스크립트 속성에 암호화(해시)되어 저장됩니다.

## 3. 시트 구성

| 탭 | 내용 |
|---|---|
| `전체기록` | 앱과 시트가 함께 쓰는 원본 데이터. 남색 제목은 입력 칸, **핑크 제목은 자동계산 칸**(직접 수정하지 마세요) |
| `연간요약` | 1~12월 합계, 연간 합계, 상·하반기 부가세(세금계산서 발행일 기준), 입금대기, 월별 차트 |
| `1월` ~ `12월` | **지급일 기준**으로 자동 분류된 목록. 맨 위에 그 달의 합계 표시 |
| `입금대기·기타` | 지급일이 비었거나 다른 연도에 입금된 건 |
| `설정` | 세율·페이백 비율·드롭다운 선택지 |

### 자동 계산 규칙
| 항목 | 계산 |
|---|---|
| 원천징수액 (3.3%) | 강사료 × 3% (10원 미만 버림) + 그 소득세의 10% (10원 미만 버림) |
| 원천징수액 (8.8%) | 강사료 × 8% (10원 미만 버림) + 그 소득세의 10% (10원 미만 버림) |
| 부가세 (세금계산서) | 강사료는 **부가세 포함** 금액 → 강사료 − 강사료 ÷ 1.1 |
| 세후강사료 | 강사료 − 원천징수액 − 부가세 |
| 페이백 | 페이백대상이 O일 때 **강사료** × 10% |
| 보조 원천징수액·실지급액 | 지급주체가 **본인**일 때만 계산 (3.3% / 8.8% 선택) |
| 강사료−보조강사료 | 강사료 − 보조강사료 (지급주체가 본인일 때만 뺌) |

## 4. 직접 고치는 방법

| 하고 싶은 것 | 방법 |
|---|---|
| 세율·페이백 비율 변경 | `설정` 탭의 값 칸(핑크)만 고치면 됩니다. 시트와 앱에 바로 반영됩니다 |
| 드롭다운 선택지 추가 | `설정` 탭 오른쪽 목록의 빈칸에 입력합니다. 단 `3.3%`, `8.8%`, `세금계산서`, `본인`, `O`는 계산식에 쓰이므로 이름을 바꾸면 안 됩니다 |
| 새 항목(칸) 추가 | `Code.gs`의 `COLUMNS`에 한 줄 추가 (예: `{ key: 'note2', header: '담당자', type: 'text', w: 100, sec: 'basic' },`) → 저장 → 시트 메뉴 **새 항목(칸) 반영**. 앱 입력 화면에도 자동으로 나타납니다 |
| 칸 순서·너비 변경 | 시트에서 직접 옮겨도 됩니다. 앱은 **제목 글자**로 칸을 찾기 때문에 제목만 바꾸지 않으면 됩니다. 옮긴 뒤에는 **월별·요약 탭 다시 만들기**를 누르세요 |
| 색상 변경 | 앱은 `Index.html` 맨 위 `:root`, 시트는 `Code.gs`의 `APP.colors`를 고칩니다 |
| 코드를 고친 뒤 앱에 반영 | **배포 → 배포 관리 → ✏ 편집 → 버전: 새 버전 → 배포**. 이렇게 하면 URL이 바뀌지 않습니다 |

## 5. 새해가 되면

시트 메뉴 **강사료관리 → 새 연도 파일 만들기**를 누르고 연도를 입력하면 `강사료관리_2027` 파일이 새로 만들어집니다.
앱 상단의 연도 선택에서 바로 바꿔 쓸 수 있습니다. 메뉴는 처음 만든 파일(스크립트가 붙어 있는 파일)에서만 보입니다.

## 6. 주의사항

- 세금 금액은 **관리용 추정치**입니다. 실제 신고는 원천징수영수증, 홈택스 발행 내역, 세무사 확인을 기준으로 하세요.
- 8.8%(기타소득)는 건당 기타소득금액이 5만 원 이하이면 과세최저한으로 세금이 없을 수 있습니다. 이 경우는 자동 계산에 반영되어 있지 않습니다.
- 부가세 신고 기간은 공급시기(세금계산서 발행일) 기준이라서, 연간요약의 부가세 반기 합계도 **발행일 기준**으로 계산합니다. 월별 탭은 요청하신 대로 **지급일 기준**입니다.
