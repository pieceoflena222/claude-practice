# 태풍 실험실

해수면 온도(SST)와 태풍 발달의 관계를 직접 조작하며 체험하는 기상과학
웹앱입니다. 초등학생과 가족 관람객이 슬라이더로 해수면 온도를 조절하면,
태풍의 크기·회전 속도·구름의 움직임이 실시간으로 변화합니다. 별도의 빌드
과정 없이 HTML / CSS / Vanilla JavaScript로 제작되어 GitHub Pages에서
바로 서비스됩니다.

## 핵심 체험

1. **실험실** 화면의 온도계 슬라이더(20°C~32°C)를 움직이면 위성 관측
   스테이지의 태풍 애니메이션(크기·회전 속도·구름 띠 색상)과 최대풍속·
   중심기압·예상 크기 게이지, 온도-풍속 관계 그래프가 즉시 갱신됩니다.
2. **관측 시작** 버튼을 누르면 그 순간의 측정값(약간의 관측 오차 포함)을
   결과로 확정하고, **이번 결과 저장**으로 계정에 기록을 남깁니다.
3. **관측 기록** 화면에서 저장한 기록을 확인하고, 이전 관측과 비교하거나
   같은 조건으로 다시 실행하거나 삭제할 수 있습니다.

태풍 발생 임계 수온(26.5°C)과 태풍 강도 구간(중/강/매우강/초강력)은 실제
기상청 기준을 참고했고, 위성 화면의 색상은 강조적외선(Enhanced IR)
위성영상 관례(약할수록 청색, 강할수록 주황~적색)를 따랐습니다. 풍속·기압
·크기 산출식은 이해를 돕기 위한 단순화된 교육용 모델이며 실제 기상
예보에는 사용할 수 없습니다.

## 로그인과 데이터 저장

회원가입한 아이디는 무작위 salt와 PBKDF2(SHA-256, 100,000회) 해시로
비밀번호를 암호화해 이 브라우저의 localStorage에 저장하고, 로그인 시
동일한 방식으로 재계산해 비교합니다. 로그인 세션과 관측 기록은 새로고침
및 브라우저 재시작 후에도 유지되며, 계정마다 기록이 분리되어 저장됩니다.
다만 서버가 없는 정적 사이트이므로 계정과 기록은 **이 브라우저(기기)
전용**이며 다른 기기와 동기화되지는 않습니다. 실제 다중 기기 계정 동기화가
필요하다면 Supabase/Firebase 등 인증·DB 서비스 연동으로 확장할 수
있습니다.

## 파일 구조

```
/
├─ index.html        화면 마크업(실험실 · 관측 기록 · 로그인 모달)
├─ css/
│  └─ styles.css      디자인 토큰, 레이아웃, 반응형, 라이트/다크 테마
├─ js/
│  ├─ physics.js       해수면 온도 → 풍속/기압/크기/강도 계산 모델
│  ├─ store.js         회원가입·로그인(PBKDF2 해시)·관측 기록 저장소
│  ├─ stage.js         위성 관측 스테이지 캔버스 애니메이션
│  ├─ chart.js         온도-풍속 관계 SVG 그래프
│  ├─ ui.js            토스트 · 모달 · 화면 전환 공용 유틸리티
│  └─ app.js           전체 화면을 엮는 메인 로직
└─ README.md
```

## 로컬 실행

```
python3 -m http.server 8000
```

이후 브라우저에서 `http://localhost:8000` 접속. 정적 파일이므로 별도의
빌드나 패키지 설치가 필요 없습니다.
