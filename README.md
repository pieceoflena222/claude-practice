# 3분 AI 업무활용 스타일 진단 (AI WORKSTYLE CHECK)

기업·공공기관·교육기관의 생성형 AI 교육 시작 전, 교육생이 자신의 AI 활용 습관을
3분 안에 점검할 수 있도록 만든 교육용 자기진단 웹앱입니다.

과학적·심리학적 진단검사가 아닌 **교육용 자기진단 도구**이며, HTML / CSS / Vanilla
JavaScript만으로 제작된 정적 웹페이지입니다. 별도의 빌드 과정이나 백엔드 없이
GitHub Pages에서 바로 열람할 수 있습니다.

## 파일 구조

```
/
├─ index.html   시작 화면 · 진단 화면 · 결과 화면 마크업
├─ style.css    디자인 시스템(컬러, 타이포, 반응형, 애니메이션)
├─ script.js    문항 데이터, 채점 로직, 화면 렌더링 로직
└─ README.md
```

## 사용 방법

로컬에서 바로 `index.html`을 브라우저로 열어 확인할 수 있고, GitHub Pages로
배포하면 별도 설정 없이 정적 사이트로 서비스됩니다. (Settings → Pages →
`main` 브랜치 루트 디렉터리 선택)

## 진단 구성

1. 시작 화면 → 12개 실제 업무 상황 질문 → 결과 분석
2. AI 업무활용 점수(0~100) + AI 업무활용 스타일(5종) + 5개 역량 분석
3. 강점 2개 / 성장 포인트 1개 / 오늘 교육 집중 영역 2개 안내
4. 결과 복사하기, 다시 진단하기, 이전 진단과 비교(localStorage) 지원

측정하는 5개 역량은 **업무정의력 · 요청설계력 · 결과검증력 · 보안감각 ·
확장활용력**이며, 문항별 점수를 역량 만점 대비 100점으로 환산한 뒤 5개 역량을
동일 비중으로 평균 내어 전체 점수를 산출합니다. 활용 스타일(실행가·탐험가·
검증가·설계자·균형가)은 12개 문항에 태그된 스타일 값을 집계해 가장 많이 나타난
유형으로 결정하며, 동점일 경우 해당 스타일 답변들의 획득 점수 합이 더 큰 쪽을
우선하고, 그래도 동점이면 균형가로 수렴합니다.

## 콘텐츠 수정 방법

문항, 선택지, 점수, 스타일 태그, 역량별 안내 문구, 점수 구간 해설 등은 모두
`script.js` 상단의 데이터 객체(`questionsData`, `styleMeta`, `strengthCopy`,
`growthCopy`, `focusCopy`, `scoreBands`)에서 관리합니다. 화면 HTML은 이 데이터를
그대로 렌더링하므로, 문항 내용을 바꾸고 싶다면 `index.html`이 아닌 `script.js`의
데이터만 수정하면 됩니다.
